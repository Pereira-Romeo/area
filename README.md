## Building the project

### Cloning the repository

You may clone the repository either using the https:
```sh
git clone https://github.com/Pereira-Romeo/area.git
```

Or by using the ssh:
```sh
git clone git@github.com:Pereira-Romeo/area.git
```

In the event that neither of these work and you're from epitech, you may try the following:
```sh
git clone git@github.com:EpitechPGE3-2026/G-YEP-500-REN-5-1-area-4.git
```
